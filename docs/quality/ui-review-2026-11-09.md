# GiveLife /new UI review — 9 November 2026

This change follows the attached `GiveLife_7_Screenshots_Final.pdf` (four actual PDF pages), the supplied screenshots, and the written requirements in this review. It does not assume earlier implementation claims are evidence of completion.

The screenshots show pages of a different 48-page PDF. That full document and prompts from other conversations were not available. The latest four-page attachment takes precedence where the references differ: DM speed options stay visible together, and Options/Back remain available alongside the active Stop action. Chat belongs on a separate screen, as explicitly requested.

## Validation and limits

Final results on the rebased changes:

- 98 redesign browser tests passed with Microsoft Playwright's official downloaded Chromium (one consolidated final run, 4.3 minutes). This includes route/tab states, every secondary dialog in the inventory, real opener and Back behavior, saved Follow-up/Notes, custom speed fields, sending-state visibility and pointer reachability, separate Chat, long Preview captions, home menu actions, and Donors defaulting to All.
- 9 reported-issue tests passed again after adding explicit Escape/outside dismissal checks and a desktop caption-to-actions spacing assertion. These are also included in the `test:e2e:new` command for future runs.
- gstack browse checked 21 routes at 390, 768, and 1440px: 63 route states, no page-wide horizontal overflow, no unexpected login dialogs, and no console errors. See [machine-readable results](ui-review-2026-11-09/gstack-route-results.json). Browser screenshots and the manual review supplement these geometry checks.
- 7 isolated group-finder browser tests passed with synthetic search.
- 18 JavaScript unit tests passed.
- 12 volunteer Python tests passed after incorporating the latest upstream `c4fc021`.
- 12 targeted volunteer/timing browser checks passed on the latest upstream `c4fc021`; the `/new` Volunteers/timing flow was also rechecked separately at four widths. Two legacy Resume tests on `/` failed because the old interface hides its Resume action. The new `/new` paused-Resume flow passes at 320, 390, 768, and 1440px.
- JavaScript syntax, changed-file formatting, and Git whitespace checks passed.

The consolidated redesign run uses independent fake preview servers for each test file, so mutable test data is not shared between workers. To repeat the complete new-studio suite: `pnpm install --frozen-lockfile`, `pnpm exec playwright install --with-deps chromium`, then `pnpm test:e2e:new`. The dedicated **New studio UI QA** workflow runs that command independently of the older interface's CI checks. It preserves the existing regression gates.

Local browser checks use Chromium and the repository's fake-WhatsApp preview, synthetic donors, and simulated delivery states. They cannot contact real WhatsApp recipients. Microsoft Playwright 1.64.1 and its official Chrome for Testing 156.0.8078.4 browser are installed. gstack 1.98.0's browse tool is also installed from the official `garrytan/gstack` repository, with Bun 1.4.4. Its browser review supplements the automated assertions and the visual review against the supplied references.

The live Render page and health endpoint were checked. Authenticated live routes require the private UI key, which was not available in this session. No claim is made that these changes are deployed or that authenticated production workflows have passed.

The matching Playwright browser exposed a three-pixel Notes toolbar overflow at 320px. The writing-mode selector now correctly permits wrapping, and compact button padding keeps the toolbar inside the viewport. The final run includes that formerly failing case. Screenshot review also caught excessive desktop space between the home caption and Next/Test; the caption no longer expands to fill the card's spare height.

The full Python run on the initial `4115e3d` base ran 1,195 tests: two failures in `test_focus_parallel`, one skip. The same two failures were reproduced in a clean `4115e3d` worktree. The wider legacy browser run also reported failures, including reading-font thresholds and hidden Resume controls on `/`; it was stopped when upstream changed so results would not mix revisions. It is not reported as an all-green regression suite.

The earlier PR CI checks also reported existing Python unused-import/variable errors before reaching browser tests. The broader CI remains separate from the new studio's passing local suite; no gates or assertions were weakened to obtain these results.

Upstream `d5685fc` was incorporated before the consolidated redesign run. Subsequent Volunteers-only updates through `c4fc021` were incorporated and rechecked with the targeted volunteer/timing browser tests and Python tests. Other redesign screens were unchanged by those upstream updates.
